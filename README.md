### Quem eu sou

**Everton Fridrich** — engenheiro de produto que transforma operação de restaurante (pedidos, cozinha, frota, pagamentos e fiscal) em software próprio de alta performance, sem depender de intermediários e taxas predatórias de marketplaces.

> Proposta de valor: *reduzir a dependência de intermediários e devolver controle operacional (PDV + delivery próprio + app de motoboys) para o restaurante, com stack multi-tenant pronta para produção.*

| Sinal | Evidência |
| :--- | :--- |
| **Produto Âncora** | **Séquito** — SaaS delivery/PDV/logística com isolamento RLS e telemetria |
| **Stack de Domínio** | Client Engineering · Realtime Logistics · Payments · Multi-tenant Data |
| **Padrões de Engenharia** | Conventional Commits, Type Safety estrita, C4 Architecture, CI/CD |

### Domínios & Responsabilidade de Engenharia

| Domínio | O que entrego |
| :--- | :--- |
| **Client Engineering** | Next.js 16 App Router, React 19, dashboards operacionais de alta vazão, PDV |
| **Mobile Field Ops** | App Expo do motoboy — OTP, GPS background, telemetria e chamada mascarada |

| **Payments & Fiscal** | Stripe, Asaas, webhooks autenticados com verificação de assinatura |
| **Platform & Security**| Supabase RLS multi-tenant por `tenant_id`, Sentry, circuit breakers |
